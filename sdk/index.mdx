`@openbat/sdk` is the TypeScript SDK for capturing AI chatbot conversations with OpenBat. You record messages, enrich them with user, organization, and session context, and OpenBat returns AI-powered analysis — sentiment, intent detection, topic classification, quality scoring, behavioral flags, and more. Messages are sent asynchronously, so capture adds no latency to your app and never throws into your code.

## Install

```bash
npm install @openbat/sdk
```

## Record your first conversation

Construct a client with your API key, then call `recordMessages()` after a conversation turn.

```typescript
import { OpenBat } from "@openbat/sdk";

const client = new OpenBat({
  apiKey: process.env.OPENBAT_API_KEY,
});

await client.recordMessages({
  conversationId: "session-abc-123",
  messages: [
    { role: "user", content: "How do I reset my password?" },
    { role: "assistant", content: "Go to Settings > Security > Reset Password." },
  ],
});
```

That's it. Messages are sent asynchronously — errors are logged to console, never thrown.

<Note>
You can pass `apiKey` to the constructor or set the `OPENBAT_API_KEY` environment variable. The client throws at construction only if `enabled` is `true` and no API key is provided.
</Note>

## What the SDK exposes

| Export | Purpose |
|--------|---------|
| `OpenBat` | Client class. `recordMessages()` captures a turn; `getSystemPrompt()` fetches a dashboard-published prompt at runtime. |
| `withOpenBat` | Wraps a Vercel AI SDK `Response`, fires capture in the background, and returns the response unchanged. |

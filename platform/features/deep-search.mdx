Deep search is a semantic search interface that finds conversations by meaning rather than exact keywords. Enter a natural-language query and it returns the conversations that match its intent, complementing the keyword search in the conversations table.

<Frame caption="The deep search page with a semantic query input, Deep Search button, and date range filter.">
  <img src="/images/platform/deep-search.png" alt="Deep search page with semantic query input and date range filter" />
</Frame>

## What you can do

- Enter a semantic search query in natural language instead of exact keywords.
- Click **Deep Search** to run the query.
- Filter results by date range using the date range picker.
- Click a search result to open its conversation detail.

## Where it lives

Deep search is at `/platform/[chatbotId]/deep-search`, reached from the chatbot sidebar under **Clients**. Use it alongside the keyword search and filters in the conversations table when you want to find conversations by intent rather than wording.

<Note>
Deep search relies on conversation embeddings. Results appear once your chatbot has captured and analyzed conversations.
</Note>

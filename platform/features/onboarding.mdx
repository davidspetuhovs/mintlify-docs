The onboarding wizard guides you through integrating the OpenBat SDK after you create a chatbot. It shows automatically once a new chatbot exists but has not been onboarded yet, walking you through copying the API key and following the SDK setup steps so the chatbot starts receiving and analyzing conversations.

<Frame caption="The new-chatbot onboarding wizard (Step 1 of 9: Basics), where you set up the chatbot before connecting the SDK.">
  <img src="/images/platform/onboarding-feature.png" alt="Onboarding wizard" />
</Frame>

## What you can do

- Copy the chatbot's API key with the copy button.
- Follow the SDK installation steps shown as code snippets.
- Track your position through the integration using the progress steps.
- Complete onboarding to mark the chatbot as set up and reach its dashboard.

## Where it lives

The wizard lives at `/platform/[chatbotId]/onboarding`. It opens automatically after you create a new chatbot from `/platform`. If the chatbot is already onboarded, the page redirects to the chatbot dashboard.

<Note>
The wizard only appears while the chatbot has not been onboarded. Once you complete it, returning to this route redirects you to the dashboard.
</Note>

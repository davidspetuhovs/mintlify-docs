The Security page details OpenBat's data protection practices for security-conscious prospects and compliance teams. It is a public page, reachable from the top navigation or footer at `/security`, so you can review it without signing in.

## What you can review

The page is organized into sections you can navigate between:

- **Encryption** — data is encrypted in transit (TLS 1.2+) and at rest (AES-256-GCM).
- **Data handling** — how OpenBat collects, stores, and processes data.
- **Access controls** — controls governing who can access data.
- **Compliance** — OpenBat's compliance posture.
- **Sub-processors** — the third-party services OpenBat relies on.
- **Incident response** — how security incidents are handled.
- **Privacy** — privacy practices.

## Documents and contact

Alongside the section content, the page links to downloadable documents and a way to reach the security team:

- **DPA** — download the Data Processing Agreement.
- **Sub-processors** — view the sub-processors list.
- **Privacy policy** — read the privacy policy.
- **Security FAQ** — review the security FAQ.
- **Contact security** — contact the security team.
